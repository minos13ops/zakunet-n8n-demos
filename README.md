# ZakuNet n8n Demos

Small, inspectable n8n workflow prototypes used to demonstrate automation architecture.

## Included

### `looker_studio_n8n_workflow.json`
Prototype for scheduled marketing reporting: Meta Ads + GA4 data collection, metric normalization, and Google Sheets as a Looker Studio data source.

### `demo_workflow_hh_automation.json`
Human-in-the-loop automation POC: webhook input, AI action extraction, approval gate, Calendar/Gmail actions, and failure alerts.

## Scope and honesty

These are prototypes, not claims of prior paid client deployments. Credentials, API keys, customer data, and production secrets are intentionally excluded.

The purpose of this repository is to show workflow structure, integration patterns, and how I approach bounded paid tests before larger engagements.
